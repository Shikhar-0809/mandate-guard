# RULES.md — enforceable. Every line is checked by `make check` or is a hard gate. No advice.

## Session
1. Fresh chat per task. Re-anchor with: GOAL, FILES, CHECK status, BASELINES, AT RISK.
2. No claim about existing code without a path:line read this session. Otherwise say "not read".
3. Plan turn first: the change, the file list, the contract test that proves it. No code in a plan turn.
4. A diff touching a file outside the approved list is rejected. Restart the plan turn.
5. Start a fresh chat after any large paste or past ~40% context.

## Done
6. A task is done only when full `make check` output and `git diff --stat` are pasted. Not "should pass".
7. `make check` = ruff check + ruff format --check + mypy --strict + pytest + pytest -m contract
   + vulture --min-confidence 80 + coverage --fail-under=80 + eval.guard + audit_verify --sample 200.
8. If `make check` cannot be run, the task is not done. Do not start the next task.

## Contracts
9. Types live in contracts/. CONTRACTS.md is generated by `make docs` and never hand-edited.
10. Any contract change ships a tests/contract/ test in the same diff.
11. Money is Money(minor_units:int, currency). No float currency anywhere. Lint-enforced.
12. Every field written to a log or audit envelope is declared in the envelope schema with a
    pii classification. An undeclared field is a failing test.
13. Untrusted content is typed UntrustedBlob and is never concatenated into a prompt or a rule
    expression. Grep-enforced.
14. The T2 verifier returns VerifierOutput only: verdict enum, evidence spans, confidence.
    It never returns an action, a threshold, or text used in control flow. Test-enforced.

## Metrics
15. baselines.json is the only accepted source of metrics. `make check` fails outside tolerance.
16. Regression beyond tolerance fails. Improvement beyond tolerance ALSO fails — check leakage first.
17. Baselines change only via `make accept-baselines REASON="..."`, which appends to DECISIONS.md.
18. The sealed set is touched only by `make seal-eval`. It increments evaluated_count.
    That count ships in the README.
19. Never inspect, plot, or tune on the sealed set. Tuning happens on data/dev/ only.
20. Every new feature passes tests/test_leakage.py: shuffled-label AUC in [0.45,0.55]
    and generator-provenance probe AUC < 0.60.
21. FP rate on Corpus B (hard negatives) must exceed Corpus A by the margin in EVAL.md,
    or the hard negatives are not hard. Test-enforced.

## Code
22. No abstraction with one implementation. Exception: `# STUB-SEAM: <name>` with an in-memory
    second implementation exercised by contract tests. tests/test_seams.py counts them.
23. vulture findings are deleted, not silenced. A noqa requires a DECISIONS.md entry.
24. No per-tenant code branches. Tenant variation is config through PolicyResolver.
    `if tenant_id ==` is a failing grep test.
25. Every reason code emitted anywhere is registered to an @rule. Test-enforced.
26. T0 reads only strongly-consistent state. Approximate or cached values are T1 features only.
27. Commented-out code fails ruff ERA. Delete it; git remembers.

## Change protocol
28. Adding a feature: read ARCHITECTURE invariants → read the contract → grep the seam (cite
    path:line) → write the failing contract test → plan turn → implement → `make check` →
    DECISIONS entry if an alternative was rejected → `make docs`.
29. Before any refactor: `make golden`. After: `make golden-diff` must be empty, or it is a
    behaviour change and needs a DECISIONS entry plus a baseline re-run.

## Docs
30. ARCHITECTURE.md ≤ 120 lines. The invariants section is mandatory. Updated in the same diff
    as any component-boundary change.
31. DECISIONS.md is append-only. Entries ≤ 10 lines: context, choice, rejected alternative,
    revisit trigger. Past entries are never edited.
32. EVAL.md is updated in the same diff as any change to generation, splits, base rates,
    or metric definitions.
33. A doc updated in a separate commit from the code it describes does not count. Same diff.

## Safety scope
34. No attack payload text outside sandbox/ fixtures. `make check` greps data/ for real VPAs,
    merchant IDs, bank identifiers, and URLs.
35. The generator emits only against sandbox/. Any target outside sandbox/ is a failing test.
36. No evasion or bypass analysis in this repository, in any framing.
